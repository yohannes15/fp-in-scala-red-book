# Functional Programming in Scala 2nd Edition (Notes and Exercises)

## Quick Intro
- Includes .devcontainer so you can open and run source code easily in any platform as long as you have Docker
- Container also includes nvim if preferred.
- Exercises and Notes are in src/main/scala/...
- This project is mostly exercises. I learned scala in another repo [scala-learning-path](https://github.com/yohannes15/scala-learning-path) if you care to see my ugly notes :)
- Only things I learn new here or find important enough get Notes. Usually comments/exercises on a scala file is enough
